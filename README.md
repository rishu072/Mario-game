# Mario-game 🎮

A simple **Mario-style 2D game** built as a fun game development project.

## 🚀 Features

* 🕹️ Player movement and controls
* 🧱 Platform-based gameplay
* ⭐ Coins and obstacles
* 🎯 Simple game mechanics
* 🎮 Mario-inspired gameplay

## 🛠️ Tech Stack

* Python
* Pygame

## ⚙️ Setup

```bash
git clone https://github.com/rishu072/Mario-game.git
cd Mario-game

pip install -r requirements.txt
```

Run the game:

```bash
python main.py
```

## 📌 About

A beginner-friendly **2D platformer game** created to practice Python, game logic, player movement, collision detection, and basic game development.
